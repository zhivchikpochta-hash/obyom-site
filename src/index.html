Open-source WebGPU library

Make 3D feel native to the web.

OBYOM is a focused browser runtime for rendering interactive 3D models with WebGPU — fast to start, easy to embed, and built for the next generation of web experiences.

03 / Quick start

Drop a viewer into your page.

Keep the integration close to the metal. The public API is intentionally compact so your product owns the experience.

Explore the source ↗
const obyom = new OBYOM({
  canvas: '#viewer',
  params: {}
});

await obyom.start();
await obyom.load('model.stl');

04 / Compatibility

Designed for capable browsers.

OBYOM requires WebGPU, a compatible browser and a secure context in production. If a device cannot provide WebGPU, the demo reports it clearly instead of failing silently.
