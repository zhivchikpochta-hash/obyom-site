# Итоги недели: OBYOM и OBYOM Site

## Период

Неделя завершилась 25 сентября 2026 года.

## Что сделано

### OBYOM — библиотека и WebGPU viewer

- Добавлено управление 3D-моделью:
  - вращение мышью и touch-жестами;
  - zoom колесом и pinch-жестом;
  - pan для desktop и mobile-сценариев.
- Исправлена проблема видимости граней STL-моделей:
  - отключён back-face culling для совместимости с моделями с неконсистентным winding;
  - сохранён depth test;
  - `depthWriteEnabled: true`;
  - `depthCompare: 'less'`.
- Исправлена проблема с отображением глубины при вращении:
  - вместо записи модели напрямую в clip-space добавлены view и projection matrix;
  - убрана ручная компрессия глубины только по оси Z;
  - добавлена отдельная normal matrix;
  - обновлены WGSL shader и WebGPU renderer.
- Восстановлен исходный оранжевый материал модели:
  - сохранён базовый цвет `#F26A21`;
  - убрано нежелательное окрашивание specular-блика цветом материала.
- Изменения библиотеки объединены и опубликованы в `master`.

### OBYOM Site — landing page и runtime integration

- Сайт переведён на реальное потребление OBYOM как GitFlic-зависимости.
- Настроена пересборка сайта из актуального `obyom/master`.
- Исправлен workflow обновления GitFlic-зависимости:
  - перед установкой удаляются `node_modules` и `package-lock.json`;
  - dependency разрешается заново;
  - generated runtime получает cache-busted имя по SHA библиотеки.
- Подключён реальный viewer с моделью сайта.
- Добавлен и переработан блок совместимости браузеров:
  - Chrome;
  - Safari;
  - Microsoft Edge;
  - Firefox;
  - минимальные версии WebGPU-браузеров;
  - пояснения о зависимости поддержки от ОС, GPU и драйверов.
- Улучшена мобильная читаемость landing page:
  - добавлено больше воздуха;
  - браузеры оформлены отдельными карточками;
  - информация о минимальных версиях сгруппирована отдельно;
  - на узких экранах элементы переходят в одну колонку;
  - устранено горизонтальное переполнение.
- Добавлена SVG-версия логотипа и настроена SVG favicon.
- Исправлено позиционирование и переполнение canvas на мобильных устройствах.
- Добавлена автоматическая сборка сайта после обновления OBYOM через GitHub Actions.
- Runtime сайта проверяется по фактическим артефактам:
  - bundle;
  - shader;
  - model;
  - resolved commit библиотеки.

## Что было проверено

- Source и generated `dist` для OBYOM синхронизированы после изменений renderer/shader.
- В актуальном OBYOM runtime присутствуют:

```text
cullMode: 'none'
depthWriteEnabled: true
depthCompare: 'less'
```

- Сайтный runtime был пересобран с актуальным commit библиотеки.
- Проверены `TypeScript` и production build.
- Проверены локальные HTTP-пути сайта и generated assets.
- Проверена мобильная ширина `390px` без горизонтального overflow.
- Проверены варианты `localhost` и `127.0.0.1` для локального preview.

## Важное ограничение проверки

Headless Chromium в текущем окружении не получил WebGPU adapter. Поэтому HTML/CSS preview и проверка HTTP-артефактов не являются полноценной проверкой реального GPU-рендера. Финальную визуальную проверку WebGPU необходимо выполнить в браузере с доступным GPU adapter.

## Следующий фокус

Следующая логичная задача для OBYOM — расширение API фона viewer’а:

1. solid background через `clearValue`;
2. gradient и procedural grid через fullscreen shader;
3. cached image background;
4. world-space floor/back planes;
5. независимые настраиваемые стороны и стены.

Важно сначала закрепить типизированный `background` API и defaults, не меняющий текущий внешний вид интеграций.

## Итог

За неделю OBYOM прошёл путь от базового viewer runtime к более устойчивой WebGPU-схеме с pointer controls, depth pipeline и реальной интеграцией в отдельный landing page. Основной технический результат — исправление рендера глубины и устранение зависимости site runtime от устаревшей версии библиотеки.
